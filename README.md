# TEKOÁ — Projeto Gestores do Futuro

Site institucional one-page do projeto TEKOÁ, dedicado à conscientização, educação ambiental e harmonia com a natureza.

## Tecnologias

- React
- Vite
- Framer Motion
- Bootstrap Icons

## Executar localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```
